# WinEDID Tool v3.2 - Windows 显卡诱骗与虚拟显示器原生管理工具

专为 Windows 显卡欺骗插头 (HDMI/DP Dummy Plug / 假负载)、软件虚拟显示器及物理显示器深度定制开发。
单文件绿色免安装，原生嵌入 UAC 管理员提权，支持 4K/2K/高刷与真实物理品牌 EDID 注入。已集成专业一机一码商业授权加密体系，支持 GitHub Actions 云端流水线全自动构建打包发布。

---

## 🌟 核心特性与重大功能

### 1. 🖥️ 虚拟显示器直接物理级诱骗 (让系统彻底认为真的有显示器)
* **注入真实物理品牌固件**：告别简陋的 `Generic Non-PnP Monitor` 或 `BAD_EDID`，直接写入正宗 **Dell Inc. 官方厂商代码 (`0x10AC`, DEL)** 与型号代码 (`0x2720`)；
* **完整的硬件特性与色域**：声明标准 EDID 1.4、物理硬件尺寸、Gamma 2.2、sRGB 与 CTA-861 音频视频扩展块（带 HDMI VSDB 4K 60Hz 声明）；
* **深度兼容各大串流与远程工具**：Windows 设备管理器、显卡驱动控制面板（AMD Radeon / NVIDIA / Intel）以及所有远程桌面与串流工具（Sunshine、Moonlight、向日葵、ToDesk）均 100% 识别为真实物理品牌显示器，完美开启 GPU 硬件编码加速与超清高刷！

### 2. 🎯 双模块常用预设与双向智能联动
* **虚拟显示器常用预设**：内置 1080P、2K、4K、1080P/2K 电竞高刷、16:10 办公黄金比、准4K 21:9 超宽带鱼屏等规格，挂载与诱骗一步到位；
* **目标诱骗分辨率常用预设**：支持 4K 60Hz/120Hz、2K 144Hz/60Hz、1080P、带鱼屏、5K/8K 等主流规格；下拉选择后输入框与时钟计算自动同步，手动微调亦可智能识别。

### 3. 🛡️ 100% 保留原有出厂分辨率 (原生分辨率标注)
* 勾选 **【保留原显示器分辨率 (原生)】** 后，工具解析硬件原始 EDID：
  - 100% 保留原厂序列号、尺寸与 Established 出厂兼容时序；
  - 槽位 1 放置新目标分辨率并打上 Native 标志，原显示器模式顺次保留在扩展区；
  - 界面与系统设置中明确标注 **`(原生分辨率)`**，防止原分辨率被冲掉。

### 4. ↩️ 一键安全恢复原生出厂配置
* 清除注册表 `EDID_OVERRIDE` 后，先触发显卡驱动 PnP 热重载；
* 执行 Windows 系统级默认模式重置（Default Mode Reset）；
* 自动提取硬件 DTD 模式，强制将屏幕物理分辨率切换回出厂原生状态，并带有驱动模式枚举后备兜底保障。

### 5. 🔐 国文创加密机商业授权对接 (一机一码 · 防二次激活)
* **动态随机申请码**：客户端启动时根据硬件指纹生成 8 位动态随机申请码（格式如：`C7MR-Y7S6`）；
* **离线加密机签发**：使用配套的【国文创加密机】可签发指定天数（半天/1天/30天/1年/永久）与启动次数的 12 位一次性激活码（`XXXX-XXXX-XXXX`）；
* **防重放与单次有效**：激活成功瞬间自动翻转本地硬件随机数并销毁旧 Nonce，同一激活码无法在该机器或其它机器二次重复使用；
* **离线防篡改**：采用 AES/HMAC 与硬件指纹联合混淆加密本地凭证，具备时钟防回拨安全防护。

## 🚀 极简使用指南

1. **直接运行**：双击运行根目录下的 **`WinEDID_Tool.exe`**；
2. **商业激活**：首次运行若提示未激活，复制界面显示的 8 位申请码，使用管理员加密机签发 12 位激活码输入即可；
3. **选择或诱骗设备**：
   - **已有物理屏幕/诱骗插头**：在「显示设备」下拉框直接选择目标设备；
   - **需要虚拟显示器**：在「虚拟显示器常用预设」中挑选所需规格（如 4K 60Hz），点击 **【⚡ 直接诱骗虚拟显示器】** 即可直接生成一台戴尔品牌真实物理显示器；
4. **配置诱骗规格**：从「常用预设」选择，或直接输入宽(W)、高(H)、刷新率(Hz)；也可随时点击 **【↩️ 填入原显示器分辨率 (原生)】** 快速回填出厂参数；
5. **一键应用**：点击 **【⚡ 一键诱骗并应用新分辨率】**，全自动注入注册表 -> PnP 热重载 -> 智能切换生效！
   - （如需清除诱骗还原，点击 **【↩️ 恢复出厂原生 (原生分辨率)】** 即可彻底还原）。

## ☁️ GitHub Actions 云端自动构建

本项目已配置纯净的 GitHub Actions 流水线，在 GitHub 云端 Windows 虚拟机环境上**只处理打包 `WinEDID_Tool.exe`**：
- 每次代码推送 (`push`) 或手动派发 (`workflow_dispatch`) 时自动运行；
- 自动编译生成独立的 `WinEDID_Tool.exe` 并打包为 Artifact；
- 自动更新 `latest` Release，可直接在 GitHub Releases 页面下载最新构建。

## 🛠️ 项目结构

- `winedid_tool.py`: 工具完整核心源码 (GUI 交互、EDID 算法、显卡热重载与分辨率切换)
- `universal_license_core.py`: 通用商业授权算法引擎 (HMAC-SHA256、40/60位混淆、多产品盐体系)
- `license_guard.py`: 运行时硬件指纹提取、申请码生成与凭证加密管理守卫
- `license_dialog.py`: 现代暗黑风格授权激活弹窗
- `WinEDID_Tool.exe`: 预编译单文件可执行程序 (内置加密授权与管理员提权清单)
- `WinEDID_Tool.spec`: PyInstaller 打包规格文件
- `.github/workflows/build.yml`: GitHub Actions 云端自动化打包与 Release 工作流
- `test_unit.py`: 单元测试套件
